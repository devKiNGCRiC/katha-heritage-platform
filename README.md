# 🏛️ KATHA - The Great Indian Heritage Platform

![KATHA Logo](./docs/assets/logo.png)

## 📖 About KATHA

**KATHA** is a comprehensive digital platform dedicated to preserving, sharing, and celebrating the rich heritage of India. From ancient history and mythology to folk tales and unheard stories, KATHA serves as a bridge connecting modern learners with timeless Indian wisdom.

### 🎯 Mission
To create the ultimate destination for Indian cultural knowledge, making our heritage accessible to learners, students, travelers, and cultural enthusiasts worldwide.

### 🌟 Vision
Empowering the next generation with deep knowledge of Indian culture, history, and values while building a vibrant community of cultural ambassadors.

## 🏗️ Project Overview

- **Type**: Full-Stack Web Application + Mobile App
- **Target Audience**: Students, Teachers, Travelers, Writers, Cultural Enthusiasts
- **Core Features**: Learning Platform, Blog, Social Community, Interactive Maps
- **Tech Stack**: MERN + React Native
- **Development Timeline**: 4 months (Sep 2025 - Dec 2025)

## 🛠️ Technology Stack

### Frontend
- **Web**: React.js with Vite
- **Mobile**: React Native
- **Styling**: Tailwind CSS + Styled Components
- **State Management**: Redux Toolkit

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB Atlas
- **Authentication**: JWT + Passport.js
- **File Storage**: Cloudinary (images/videos)

### DevOps & Tools
- **Version Control**: Git + GitHub
- **Code Editor**: VS Code
- **API Testing**: Postman
- **Design**: Figma
- **Documentation**: Notion
- **Deployment**: Vercel (Frontend) + Railway (Backend)
