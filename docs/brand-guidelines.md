# 🎨 KATHA Brand Guidelines & Visual Identity

## 🎯 Project Identity

### **Brand Name**: KATHA
**Meaning**: "Story" or "Tale" in Sanskrit
**Tagline**: "Preserving the past, inspiring the future"

---

## 🎨 Logo Concept

Since I can't create actual images, here's a detailed description for you to create in Figma:

### **Primary Logo Design**
```
🏛️ KATHA
```

**Elements:**
1. **Temple Icon (🏛️)**: Represents Indian architecture and heritage
2. **Typography**: 
   - Font: Bold, Modern Sans-serif (like Montserrat or Poppins)
   - "KATHA" in capital letters
   - Slight curve or flourish inspired by Devanagari script

### **Color Palette**

**Primary Colors:**
- **Saffron Orange**: #FF6B35 (Energy, wisdom, courage)
- **Deep Blue**: #004E89 (Stability, trust, depth)
- **Gold**: #FFD700 (Prosperity, heritage, value)

**Secondary Colors:**
- **Cream White**: #FFF8E7 (Purity, peace)
- **Charcoal**: #2D3436 (Text, elegance)
- **Soft Green**: #00B894 (Growth, harmony)

**Usage:**
- Headers: Deep Blue or Saffron Orange
- Body Text: Charcoal
- Backgrounds: Cream White
- Accents: Gold
- Success states: Soft Green

### **Typography Hierarchy**

```css
/* Headings */
h1: 2.5rem, font-weight: 700, color: Deep Blue
h2: 2rem, font-weight: 600, color: Deep Blue
h3: 1.5rem, font-weight: 600, color: Charcoal

/* Body Text */
body: 1rem, font-weight: 400, color: Charcoal
small: 0.875rem, font-weight: 400, color: Charcoal

/* Special */
.hero-title: 4rem, font-weight: 800, gradient (Saffron to Gold)
.tagline: 1.25rem, font-weight: 300, color: Cream White
```
